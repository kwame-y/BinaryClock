# Project Images

Exported from the packaged BinaryClock3 snapshot with KiCad 10.0.3 on October 17, 2026.

- `BinaryClock3.svg`: schematic.
- `FrontLayout.svg` / `BackLayout.svg`: copper, silkscreen, and outline.
- `FrontSilkscreen.svg` / `BackSilkscreen.svg`: silkscreen and outline.
- `Inner1.svg` / `Inner2.svg`: inner copper layers and outline.
- `Front3D.png` / `Back3D.png`: direct 3D renders using the saved stackup colors.

Back-side SVG views are mirrored to view the board from the back. Some component bodies are missing from the 3D renders because models are absent or unassigned. No component placement or routing was changed for these exports.
